# Ngoc Ngo Portfolio — V6

Personal portfolio for Ngoc Ngo, Product Designer / UI/UX Designer.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## V6 direction
- Editorial dark visual system
- Stronger visual rhythm and hierarchy
- Product-first case study storytelling
- Flo, Scheduler Management, Cryprice
- Responsive desktop/tablet/mobile foundation

The current product visuals are coded placeholders and should be replaced selectively with real product screenshots, GIFs, prototypes, or video captures.
